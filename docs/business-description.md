# 宠物服务预约平台 · 小程序端业务说明

> 本文档描述小程序客户端的业务流程和功能模块，供后端开发理解业务上下文。

---

## 1. 平台概述

宠物服务预约平台分为两端：
- **客户端（本小程序）**：客户浏览服务、预约下单、支付、评价
- **管理端**：门店员工管理预约、排班、服务

本小程序为**单店模型**，客户进入小程序后看到的是一个门店的服务。

---

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 未登录用户 | 可浏览首页、服务列表、服务详情，不可预约 |
| 已登录客户 | 可预约、管理宠物、管理地址、查看订单、评价 |

> 登录方式：微信一键登录（wx.login → code2Session）

---

## 3. 核心业务流程

### 3.1 预约下单流程

```
浏览服务 → 选择服务 → 选择宠物 → 选择技师和时段 → 确认下单 → 支付 → 待服务
```

**详细步骤**：

1. 客户进入首页或服务列表，浏览服务项目/套餐
2. 点击"立即预约"进入预约下单页面
3. 第一步：确认选择的服务（可切换其他服务）
4. 第二步：选择宠物（如无宠物需先添加，疫苗过期不可选）
5. 第三步：选择日期和时段（系统展示各技师可用时段）
6. 第四步：确认订单信息，填写备注，提交
7. 系统自动调用模拟支付，状态从"待支付"变为"待服务"

### 3.2 预约状态流转

```
客户下单 → 待支付(1) → 待服务(2) → 服务中(3) → 已完成(5) → 已评价(6)
                ↓              ↓
            已取消(4)      已取消(4)
```

| 当前状态 | 客户可执行操作 | 说明 |
|----------|--------------|------|
| 1 待支付 | 支付、取消 | 30分钟未支付自动取消 |
| 2 待服务 | 取消 | 取消后释放时段 |
| 3 服务中 | 无 | 等待技师完成服务 |
| 4 已取消 | 无 | 终态 |
| 5 已完成 | 评价 | 引导客户评价 |
| 6 已评价 | 无 | 终态 |

### 3.3 宠物管理流程

1. 客户进入"我的宠物"页面
2. 添加宠物：填写名字、类型、品种、体重、疫苗日期等
3. 编辑宠物：修改宠物信息
4. 删除宠物：有未完成预约时不允许删除
5. **疫苗过期约束**：预约时校验宠物疫苗有效期，过期不可预约

### 3.4 地址管理流程

1. 客户进入"地址管理"页面
2. 添加地址：选择省市区 + 填写详细地址 + 联系人
3. 设置默认地址
4. 编辑/删除地址

> 地址用于上门服务场景（如果门店提供上门服务）

## 4. 页面功能说明

### 4.1 首页 `pages/index/index`

**用途**：门店门户，展示核心信息引导下单

**模块**：
- 门店横幅：Logo、名称、营业状态标签
- 联系卡片：地址（可复制）、电话（可拨打）
- 分类入口：横向滚动分类图标，点击跳转服务列表并筛选
- 热门服务：展示前 6 个服务项目卡片
- 超值套餐：横向滚动套餐卡片，展示折扣信息

### 4.2 服务列表 `pages/service/list`

**用途**：浏览所有服务项目

**功能**：
- 分类 Tab 筛选（全部 + 各分类）
- 搜索框（按名称模糊搜索）
- 服务卡片列表（图片、名称、时长、体型限制、价格）
- 下拉刷新 + 上拉加载更多
- 点击卡片进入服务详情

### 4.3 服务详情 `pages/service/detail`

**用途**：展示单个服务/套餐的完整信息

**功能**：
- 大图展示
- 名称、价格、时长、适用体型、分类标签
- 详细描述
- 套餐页额外展示包含的服务项目明细
- 底部"立即预约"按钮

### 4.4 预约下单 `pages/appointment/create`

**用途**：4 步完成预约流程

**步骤**：
1. **选择服务**：确认或切换服务项目
2. **选择宠物**：从我的宠物中选择，校验疫苗有效期
3. **选择时段**：日期选择（近 7 天）+ 技师选择 + 可用时段选择
4. **确认下单**：订单摘要 + 备注 + 提交支付

### 4.5 我的预约 `pages/appointment/list`

**用途**：查看和管理所有预约

**功能**：
- 6 个状态 Tab：全部/待支付/待服务/服务中/已完成/已评价
- 预约卡片列表（单号、服务、技师、时间、金额、状态）
- 操作按钮：
  - 待支付 → "去支付"
  - 待服务 → "取消预约"
  - 已完成 → "去评价"
- 下拉刷新 + 上拉加载更多

### 4.6 预约详情 `pages/appointment/detail`

**用途**：查看单个预约的完整信息

**展示**：
- 状态横幅（颜色区分状态）
- 订单信息：单号、创建时间
- 服务信息：项目名称、时长、价格
- 宠物信息：名字、品种
- 技师信息：姓名、等级
- 预约时间：日期、时段
- 支付信息：金额、支付状态、支付时间
- 备注、取消原因
- 底部操作按钮（根据状态显示）

### 4.7 宠物管理 `pages/pet/list` + `pages/pet/edit`

**用途**：管理我的宠物档案

**功能**：
- 宠物列表（卡片展示，点击进入编辑）
- 添加宠物（表单页）
- 编辑宠物（回填数据）
- 删除宠物（长按触发确认）
- 疫苗状态标记（绿色=有效，红色=已过期）

### 4.8 地址管理 `pages/address/list` + `pages/address/edit`

**用途**：管理上门服务的地址

**功能**：
- 地址列表（默认地址置顶标记）
- 添加/编辑地址（省市区选择器 + 详细地址）
- 删除地址
- 设置默认地址

### 4.9 评价 `pages/review/create` + `pages/review/list`

**用途**：客户评价和查看历史评价

**功能**：
- 发表评价：星级评分（1-5）+ 文字 + 图片（最多 3 张）
- 我的评价列表：展示历史评价 + 商家回复
- 一条预约只能评价一次

### 4.10 个人中心 `pages/profile/index`

**用途**：用户信息和功能入口

**功能**：
- 用户信息卡片（头像、昵称、手机号）
- 未登录时显示"点击登录"
- 功能菜单：我的宠物、地址管理、我的评价、联系客服、关于我们
- 退出登录

## 6. 关键业务规则

### 6.1 疫苗过期校验

- 预约时检查宠物 `vaccineExpiryDate`
- 如果 `vaccineExpiryDate < 当天日期`，不允许选择该宠物
- 前端用红色标签提示"疫苗已过期"

### 6.2 可约时段计算

- 输入：日期 + 服务项目（或套餐）
- 输出：每个可用技师的可用起始时间列表
- 计算逻辑：
  1. 获取服务时长 duration
  2. 查询当日有排班的技师
  3. 过滤有资质的技师
  4. 将排班时间按 30 分钟切片
  5. 减去已占用的时间片
  6. 找出连续可用 duration 分钟的起始点

### 6.3 时段冲突检查

- 同一技师同一时段只能接一个预约
- 通过 `appointment_slot` 表的唯一索引保证
- 冲突时提示"该时段已被预约，请选择其他时段"

### 6.4 超时自动取消

- 待支付状态超过 30 分钟自动取消
- 取消时释放已占用的时间片
- 已支付的订单不会被误取消

### 6.5 评价规则

- 只有"已完成"状态的预约可以评价
- 一条预约只能评价一次
- 评价后预约状态变为"已评价"
- 商家可以回复评价（管理端操作）

## 7. 前端技术要点

### 7.1 技术栈

- uni-app + Vue 3 `<script setup>` + Pinia
- SCSS scoped styles
- dayjs 日期处理
- 目标平台：微信小程序 + H5

### 7.2 请求封装

- `uni.request` 封装在 `utils/request.js`
- 自动添加 `authentication` 请求头
- 统一处理 401 跳转登录
- 统一错误提示 toast

### 7.3 状态管理

- Pinia store 管理用户登录状态
- token 存储在 `uni.setStorageSync`
- 页面内状态使用 `ref` / `reactive`

### 7.4 枚举管理

- 所有状态码定义在 `constants/enums.js`
- 前端使用数字比较，不使用字符串
- StatusTag 组件统一渲染状态标签

## 8. 部署说明

### 8.1 开发环境

```bash
cd D:\pet-wx-users-kit
npm install

# H5 开发
npm run dev:h5
# 访问 http://localhost:8082

# 微信小程序开发
npm run dev:mp-weixin
# 用微信开发者工具打开 dist/dev/mp-weixin 目录
```

### 8.2 生产构建

```bash
# H5 构建
npm run build:h5

# 微信小程序构建
npm run build:mp-weixin
# 用微信开发者工具上传 dist/build/mp-weixin
```

### 8.3 微信小程序配置

需要在 `src/manifest.json` 中填写：
- `mp-weixin.appid`：小程序 AppID
- 服务器域名白名单（在微信公众平台配置）

## 9. 与管理端的协同

| 操作 | 管理端 | 小程序端 |
|------|--------|---------|
| 创建预约 | 代客下单 | 客户自助下单 |
| 核销到店 | 点击"核销"按钮 | 技师扫码或手动确认 |
| 完成服务 | 点击"完成"按钮 | 技师完成后自动流转 |
| 取消预约 | 商家可取消并退款 | 客户可取消（待支付/待服务状态） |
| 排班 | 设置排班时间 | 查看可用时段 |
| 评价 | 回复评价 | 发起评价 |
| 宠物信息 | 只读查看 | 增删改 |
| 门店设置 | 修改配置 | 只读展示 |
